# Briefs

Sample briefs for `compile_spatial_brief` / the brief router.

Note: `affordance`, `camerapeek`, `ramenlos`, `ramenoccupancy`, `ramenworld`, and
`stationsemantic` reference world-model assets that live on the maintainer's machine and are not
distributed; on other machines the asset gate names the missing prerequisite and the brief skips
honestly. The remaining briefs are machine-independent.

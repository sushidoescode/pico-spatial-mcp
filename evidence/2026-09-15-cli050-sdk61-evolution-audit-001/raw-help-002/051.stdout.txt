Usage:
  $ pico-cli emulator setup

Options:
  --format <format>  Output format (plain, json) (default: plain)
  --launch-studio    Launch Android Studio when setup guidance requires it (default: false)
  -h, --help         Display this message 

Examples:
  $ pico-cli emulator setup
  $ pico-cli emulator setup --launch-studio
  $ pico-cli emulator setup --format json

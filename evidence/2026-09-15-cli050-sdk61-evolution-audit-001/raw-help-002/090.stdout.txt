Description:
Install an APK to the preferred current device

Usage:
  $ pico-cli app install <path>

Options:
  -d, --device <device>    Target device id (overrides automatic selection)
  -r, --replace            Replace an existing application
  --downgrade              Allow version code downgrade (adb install -d)
  -t, --test               Allow test packages
  -g, --grant-permissions  Grant runtime permissions on install
  -h, --help               Display this message

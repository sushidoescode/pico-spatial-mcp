Description:
Update plugins already recorded by setup; does not initialize dependencies or switch platforms

Usage:
  $ pico-cli plugin update

Options:
  --agent-tool <tools...>  Recorded Agent Hosts to update; defaults to every Host recorded in the
                           selected scope; all must be used alone (all | claude-code | codex |
                           cursor | copilot | traecli)
  --scope <scope>          [required] Recorded plugin resource scope (global | local)
  --platform <platform>    Filter Hosts by their recorded platform; omit to preserve and update each
                           Host's platform (spatial | unity)
  --cwd <path>             Override the global plugin workspace parent directory
  --project <path>         Target application project root for AGENTS refresh; also selects local
                           resources/state in local scope and defaults to the exact current
                           directory
  --format <format>        Output format (plain | json) (default: plain)
  -h, --help               Display this message

Examples:
  $ pico-cli plugin update --scope global
  $ pico-cli plugin update --scope global --project /absolute/path/to/project
  $ pico-cli plugin update --scope global --agent-tool all
  $ pico-cli plugin update --scope global --agent-tool codex traecli
  $ pico-cli plugin update --scope local --project /absolute/path/to/project --agent-tool all

Description:
Check SpatialML project configuration and workspace state

Usage:
  $ pico-cli spatialml doctor [--project <path>] [--format plain|json]

Options:
  --project <path>   Native OpenXR, Unity, or Kotlin Spatial SDK project directory (default: .)
  --format <format>  Output format (plain | json) (default: plain)
  -h, --help         Display this message

Examples:
  $ pico-cli spatialml doctor
  $ pico-cli spatialml doctor --project apps/demo --format json

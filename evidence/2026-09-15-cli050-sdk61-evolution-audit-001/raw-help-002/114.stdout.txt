Description:
Uninstall all or a selected Spatial Editor version

Usage:
  $ pico-cli editor uninstall

Options:
  --editor-version <version>  Uninstall only the specified exact Spatial Editor version
  -y, --yes                   Assume yes for prompts
  -h, --help                  Display this message

Examples:
  $ pico-cli editor uninstall
  $ pico-cli editor uninstall --editor-version 6.0.0 -y

Usage:
  $ pico-cli project create --name <text> --package <text> --template <text> [options]

Options:
  --dir <path>       Output directory (default: current directory) 
  --name <text>      [required] Project name 
  --package <text>   [required] Package name, e.g. com.example.app 
  --sdk-type <text>  Override the SDK type; defaults to the platform recorded in .pico-env.json (spatial | unity) 
  --template <text>  [required] Template mode (spatial: planar/volumetric/stage; unity: OpenXR/PICOXR) 
  --sdk <text>       Spatial SDK BOM version (optional) 
  --force            Allow overwriting an existing Gradle project in the output directory (default: false)
  -h, --help         Display this message 

Examples:
  # Panel-first app with mostly 2D UI
  $ pico-cli project create --template planar --name demo --package com.example.demo
  # 3D model viewer or product showcase
  $ pico-cli project create --template volumetric --dir apps/demo --name demo --package com.example.demo
  # Immersive or room-scale spatial experience
  $ pico-cli project create --template stage --name demo --package com.example.demo --force
  # OpenXR runtime app
  $ pico-cli project create --template OpenXR --name demo --package com.example.demo
  # PICO XR runtime app
  $ pico-cli project create --template PICOXR --dir apps/demo --name demo --package com.example.demo

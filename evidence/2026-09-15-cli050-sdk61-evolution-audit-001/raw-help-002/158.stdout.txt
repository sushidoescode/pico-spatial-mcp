Description:
Inspect a LiteRT model with pyspatialml

Usage:
  $ pico-cli spatialml model inspect <model> [--format plain|json]

Options:
  --format <format>  Output format (plain | json) (default: plain)
  -h, --help         Display this message

Examples:
  $ pico-cli spatialml model inspect model.tflite
  $ pico-cli spatialml model inspect model.tflite --format json

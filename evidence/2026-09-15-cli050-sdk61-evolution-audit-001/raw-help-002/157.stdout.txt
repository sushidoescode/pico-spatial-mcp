Description:
Check project-local agent context routing

Usage:
  $ pico-cli project context doctor [options]

Options:
  --agent-tool <tools...>  Agent Hosts to inspect; omit to use project-local setup records (all |
                           claude-code | codex | cursor | copilot | traecli)
  --source <path>          Plugin workspace/source root containing published plugin context
  --fix                    Copy and link project-local agent context routing when incomplete
  --format <format>        Output format (plain | json) (default: plain)
  -h, --help               Display this message

Examples:
  $ pico-cli project context doctor
  $ pico-cli project context doctor --agent-tool traecli
  $ pico-cli project context doctor --format json

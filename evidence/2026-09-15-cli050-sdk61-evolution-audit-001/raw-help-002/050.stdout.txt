Usage:
  $ pico-cli emulator list

Options:
  --format <format>  Output format (table, json, plain) (default: table)
  --managed-only     Only show CLI-created PICO emulators (default: false)
  -h, --help         Display this message 

Examples:
  $ pico-cli emulator list
  $ pico-cli emulator list --managed-only
  $ pico-cli emulator list --format json
